# StockWatch

一个低存在感的 macOS 菜单栏行情小窗，第一版面向 A 股和港股自选观察。

## 当前功能

- 菜单栏小窗口，不显示 Dock 图标。
- 默认自选：腾讯控股、贵州茅台、平安银行。
- 支持分组 tab，可新增、删除分组，并自定义当前分组名称。
- 支持添加/删除股票，输入格式包括 `700`、`00700`、`HK.00700`、`600519`、`SZ.000001`。
- 中文输入支持搜索联想，点建议项可直接加入当前分组。
- 按行展示名称、代码、价格、涨跌幅和当天迷你走势线。
- 低调模式默认开启，涨跌颜色使用灰度；可在右上角切换。
- App 直连腾讯公开行情接口，不需要本地 Python server。

## 运行

```bash
swift run StockWatch
```

## 打包成 App

```bash
bash Scripts/build_app.sh
open dist/StockWatch.app
```

已打包的 App 位置：

```text
dist/StockWatch.app
```

## 说明

腾讯公开行情适合个人自用观察；不建议作为交易级或商用行情源。
